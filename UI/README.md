## Cài đặt môi trường

### Đối với Python

Mở Terminal hoặc CMD tại thư mục dự án.

Tạo môi trường ảo:

```bash
python -m venv venv
```

Kích hoạt môi trường ảo:

**Windows:**
```bash
venv\Scripts\activate
```

### Đối với JavaScript

Kiểm tra Node.js:

```bash
node --version
```

Nếu dự án có file `package.json`, cài đặt các thư viện:

```bash
npm install
```

Nếu không sử dụng thư viện bên ngoài, có thể bỏ qua bước này.

## Hướng dẫn chạy chương trình

### Chạy file Python (main.py)

Sử dụng lệnh:

```bash
python main.py
```

Nếu hệ thống không nhận diện lệnh `python`, thử:

```bash
py main.py
```

### Chạy file JavaScript (main.js)

Sử dụng lệnh:

```bash
node main.js
```
```

Chúc bạn cài đặt và chạy chương trình thành công!
